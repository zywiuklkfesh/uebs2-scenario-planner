## Overview

Ultimate Epic Battle Simulator 2 Scenario Planner helps players design battles before launching UEBS2, configuring unit counts, team compositions, spawn positions, and terrain selection. It estimates the battle's GPU load to warn when a scenario exceeds typical hardware limits and saves scenarios for repeat playback.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Ultimate Epic Battle Simulator 2 Scenario Planner** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Force Designer** | Configure army composition and unit counts for both battle teams |
| **Spawn Layout** | Plan spawn zone positions on a top-down map grid |
| **GPU Load Estimate** | Estimates GPU particle count to predict frame rate at high unit counts |
| **Scenario Save** | Save designed scenarios and reload them in future sessions |
